隐私政策

双木林网申助手 浏览器扩展（以下简称"本扩展"）。

我们收集什么

本扩展不收集任何用户数据。 所有信息仅存储在用户本地浏览器中，不会上传至扩展开发者或任何第三方分析/统计服务器。

数据流向说明

用户粘贴的简历内容保存在浏览器本地 chrome.storage.local。当用户主动点击"自动填表"时，当前网页的表单字段信息与简历内容会通过 HTTPS 发送至用户自行配置的 AI 服务地址（如 OpenAI、DeepSeek 等），用于智能匹配与字段填充。AI 服务商对数据的处理受其各自隐私政策约束，用户可自行选择信任的 AI 服务商。

用户随时可通过弹窗清除已保存的简历和 API 密钥。

权限说明

  • storage：在用户本地保存简历与 API 配置。
  • host_permissions：因不同企业网申系统域名不固定，且用户可自由指定 AI 服务地址，需访问用户操作的网页及用户配置的 API 地址。

第三方

本扩展不含任何广告 SDK、统计埋点或数据共享组件。我们不将用户数据出售或转让给任何第三方。
